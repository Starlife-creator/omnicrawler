# 兼容与回滚

> 适用版本：1.0.26 · 配置协议：v5 · 维护状态：现行

> 当前版本：1.0.26。本文件描述 1.x 的兼容与回滚策略；1.0.26 为**工具与文档门禁收口版本**，
> 不含面向用户的运行时功能变更。

## 兼容性保证

- 配置协议保持 v5，Task IR、SDK（validate/compile/run/query）和 CLI 子命令语义保持稳定。
- **1.0.26 不改变任何运行时行为**：本版集中在质量门禁与测试基建（文档派生数字门禁、
  子进程编码约定、门禁清单守卫），未新增或修改 CLI 参数、配置键、任务模型、工作区布局、
  证据与导出格式。未指定新参数时行为与 1.0.1 完全一致。
- 旧版配置仍由既有迁移流程升级；GUI 偏好写入 QSettings，旧版会忽略不认识的偏好。
- 任务网络边界、robots、范围、预算、凭据作用域与审计规则不因升级而放宽。
- **例外（沿用 1.0.x 既有收紧，非本版新增）**：`http.verify_tls: false` 必须配合
  `http.tls_insecure_domains` 使用，且只对该名单内主机生效——名单外主机会被出网层拦截。
  迁移：把原先「全局关闭」的配置改成「要么设回 `verify_tls: true`，要么把确实需要免校验的
  主机写进 `tls_insecure_domains`」。配置校验会直接给出这条提示，不会静默改变行为。

## 回滚

- 1.0.26 与 1.0.1 之间可**直接互换**：无配置迁移、无状态库结构变更、无资产格式变化。
- 先停止 GUI 和 Worker，再复制工作区；SQLite 状态、证据和配置仍可使用。
- 回滚到不理解新字段的版本时，按既有未知字段策略保留或忽略；不要手工删除任务数据。
- 便携版回滚使用完整的同版本文件夹或 ZIP，不要混用不同版本的 EXE、`_internal`、浏览器或运行时资产。
