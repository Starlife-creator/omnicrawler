# 兼容与回滚

> 当前版本：0.9.0。本文件描述从 2.0+ 升级到 0.9.0 的兼容性策略。

## 兼容性保证

- 配置协议保持 v5，Task IR、SDK（validate/compile/run/query）和 CLI 子命令语义保持稳定。
- 0.9.0 的首页任务优先交互、自然语言草案和 GUI 生命周期修复不改变工作区格式、任务配置、证据或导出格式。
- 旧版配置仍由既有迁移流程升级；新增 GUI 偏好写入 QSettings，旧版会忽略不认识的偏好。
- 任务网络边界、robots、范围、预算、凭据作用域与审计规则不因升级而放宽。

## 回滚

- 先停止 GUI 和 Worker，再复制工作区；SQLite 状态、证据和配置仍可使用。
- 回滚到不理解新字段的版本时，按既有未知字段策略保留或忽略；不要手工删除任务数据。
- 便携版回滚使用完整的同版本文件夹或 ZIP，不要混用不同版本的 EXE、`_internal`、浏览器或运行时资产。
