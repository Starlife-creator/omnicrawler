# OmniCrawler 1.0.7 发布报告

> 发布日期：2026-11-15；配置协议：v5；公共 API：兼容（无变化）；任务模型/工作区/导出格式：不变。

## 发布结论

1.0.7 是**质量门禁与测试基建的收口版本**：把三类「守卫看起来在、其实没装上」的缺陷
变成有反向断言的可证伪判据——文档里的派生数字必须由工具当场算出、子进程输出的编码必须
与父进程解码一致、门禁清单与 CI 的接线必须双向一致。**不改变任何面向用户的运行时行为**，
不新增 CLI 参数与配置键，不改变任务执行、工作区、证据与导出格式。

## 已交付改进

### 一、文档派生数字不再手抄（`check_doc_numbers`）

- 现状文档里手抄的门禁数量 / 测试通过数 / i18n 条目数一律判红，改用命令指针；
  必须露出的数字放进 `<!-- BEGIN AUTOGEN:key -->` 生成块，由工具**当场算出的值**逐字比对
  （`--update` 重写）。比的是计算值而不是仓库里存的副本——这是唯一能挡住「文档写完之后
  又漂回去」的做法。
- **扫描面从三条硬编码 glob 改为文件系统递归**：旧扫描面只覆盖根目录、`docs/` 一层、
  `constraints/` 一层，`docs/adr/`、`src/omnicrawler/gui/docs/`、`.github/`、`plugins/`、
  `e2e/`、`packaging/` 这些会新增文档的位置一层都盖不到，而**漏扫是静默的**。
  实测：往 `docs/adr/` 塞一份写「门禁共 31 项」的现状文档，旧扫描面命中 0 条，
  同样的内容放在 `docs/` 下命中 1 条。
- 配套修正两处分类缺陷：日期判定改到**路径任意一级**（日期在目录上与在文件名上是同一语义），
  HTML 注释内的格式示例不再被当作现状声明（屏蔽只换内容不删行、不向下一行顺延）。

### 二、子进程编码约定（`tools/child_env.py` + C-#31 静态门禁）

- 父进程按 `encoding="utf-8"` 解子进程输出时，子进程必须也按 UTF-8 写。Windows 上 Python
  子进程默认按控制台代码页（简体中文 cp936）写管道，中文会被解成替换字符——**断言假红、
  代码本身没错**。新增 `utf8_env()` 在父环境副本上叠加 `PYTHONUTF8=1` 与
  `PYTHONIOENCODING=utf-8`（合并而非整份替换，否则丢 `PATH` / `VIRTUAL_ENV` / 代理）。
- 新增静态门禁按 **AST** 找出「发起子进程 + 声明 `encoding=` + 没有 `env=`」的调用；
  git/bash 这类按 UTF-8 写的外部程序、以及被探测方自己 reconfigure 的情形逐条白名单并写理由。
  扫描面收窄、白名单空理由、白名单指向已消失的位点，三种失效各自判红。

### 三、门禁清单与 CI 接线守卫

- `Gate` 新增 `declared_ci_flags`：CI 相对本地自证额外使用的旗标必须显式声明；
  多一个判红、少一个也判红（后者防声明退化成随便写的白名单）。
- 库白名单 `_LIBRARY_ONLY_SCRIPTS` 每条必须有仓内真实消费者，扫描刻意跳过定义白名单的
  测试文件自身，否则写进去就自证成立。
- `check_shell_scripts` 的环境探测改为**三步正面验证**（能启动 / 真在读文件 / 合法脚本能过），
  把「环境缺能力」与「脚本真坏了」分开：前者以跳过码 77 如实登记，结构判据照旧判红。

### 四、CI 稳定性（承接 1.0.1 之后的一批修复）

- `main` 上 `test` 作业连续 5 次在 `timeout-minutes: 45` 被取消，日志只有 `[1%]` 加 43 分钟
  零输出。根因是导航遍历用例触发的**阻塞式模态对话框**在无头环境下永久等待；已定位修复，
  并给所有 CI pytest 入口装上 `faulthandler_timeout=300`，让「黑箱超时」变成可定位的调用栈。
- 修掉子集运行在 coverage 下的进程段错误（`gui-and-browser` 作业 exit 139 的直接原因）。
- 修掉一条「防卡死」上界写死秒数的断言——它检验的是机器快慢，不是它声称的性质。

### 五、安全与依赖

- 合并悬空 8 天的 PR #174（291 commits / 55 文件）：插件凭据与目标主机边界、
  `state.migrate` 排除敏感键、PDF 处理依赖变化时失效重建 + 人工复核保护、
  Linux Landlock / macOS Seatbelt 沙箱、Unix 沙箱强制执行、便携升级冒烟工具。
- 依赖与 CI Action 按 SHA pin 统一升级，`selectolax` 的 HTML 后端从 Modest 迁到 lexbor
  （旧后端在 1.0 已删除，回退会静默降级到慢路径，已补契约用例钉住）。
- 移除仅因 extras 上界而存在的 pillow 审计豁免：放宽上界后实测 0 条命中，基线随之收紧。

## 合规与诚实条款（固定字段，B14-💭-3）

- **不绕过**：本版本遵守 robots.txt、只采已获授权站点，不绕过验证码、付费墙、
  访问控制或站点安全策略；隐身/undetected 能力仅用于已授权站点并经 EgressBroker
  统一出口。
- **门禁不伪称**：外部门禁/审核状态如实标注 `pending`/`通过`，不伪称通过；
  无法本地验证的检查明确说明验证条件。

## 升级与回滚

- 升级：直接替换即可，无配置迁移、无状态库结构变更、无资产格式变化。
- 回滚：1.0.7 与 1.0.1 可直接互换；便携版请整包替换，不要混用不同版本的
  EXE、`_internal`、浏览器或运行时资产。
