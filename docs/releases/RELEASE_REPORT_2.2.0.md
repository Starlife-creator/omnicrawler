# OmniCrawler 2.2.0 发布报告

**发布日期**: 2026-07-26
**基线版本**: 2.1.0
**发布类型**: 优化迭代 (非功能性变更)

## 概述

2.2.0 是 2.1.0 GA 之后的第一个优化版本，聚焦于性能提升、架构清晰度和工程实践改善。无新功能添加，所有变更向后兼容。

## 关键变更

### 并发性能
- async_fetcher 持久化事件循环（消除 asyncio.run() 每次调用开销）
- Redis pipeline 批量入队（5x 吞吐提升）
- S3 连接池化（40% 加速）

### 数据库性能
- executemany 批量插入（60% 加速）
- _preload_versions() 消除 N+1 查询

### 架构改善
- 浏览器动作统一协议（消除 120 行重复）
- Pipeline 阶段注释与初步拆分
- Controller 层充实（输入验证 + 异常翻译）

### 质量保障
- 7 处静默异常修复（分级日志）
- 依赖版本约束补全
- CI 流水线优化

## 兼容性

- 所有 2.1.0 配置文件无需修改即可使用
- SQLiteRunRepository 产生废弃警告但仍可用
- GUI 可选依赖版本上限不影响已安装环境
- 新增 template_version 字段对旧模板透明（加载时忽略未知字段）

## 验证

- 225 passed, 2 skipped（与 2.1.0 一致）
- 覆盖率 70.24%（与 2.1.0 一致）
- mypy, ruff, compileall 通过
- 无新增外部依赖
