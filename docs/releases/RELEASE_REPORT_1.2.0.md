# OmniCrawler 1.2.0 发布报告

 > 发布日期：2026-11-28；配置协议：v5；公共 API：兼容（无破坏性变化）；
 > 任务模型 / 工作区 / 导出格式：不变。

## 发布结论

1.2.0 是**插件界面扩展 + 配置错误前置 + 性能收口**的版本。

三条主线：

1. **插件能做的事变多了**：声明式视图可以贡献中央整页、可以用前景层，
   插件页进 Ctrl+K；配套补齐 `theme.apply` 与 `requires_components` 的消费链路。
2. **配置写错在写的时候就知道**：JSONPath / CSS / 正则 / XPath 四类语法错误
   全部前移到 `validate` 阶段，并点名具体字段。
3. **抓取与导出更快**：HTTP 连接复用、同页只解析一次、xlsx 流式写出、
   GUI/CLI 冷启动多处惰性化。

**不改变**：配置协议版本、任务执行模型、工作区结构、证据与导出格式。

## 已交付改进

### 一、插件界面能力扩展

- `preferred_zone: main`：插件可以贡献**中央整页**（此前只能做 190px 侧栏面板）。
  硬约束由代码结构保证——导航行只能追加在末尾、卸载成对清理、
  重排按 key 整体重算，不会重现历史上的「结果与复核错页」。
- `surface.foreground.*`：前景层（浮层）能力。overlay 的 parent 是 `centralWidget`，
  因此**结构上**盖不住菜单 / 停靠面板 / 对话框；三档 z 只有 `underlay`/`overlay`/`modal`。
- 描述符内新增 `foreground` 段（浮层初始声明），与运行期能力分工明确。
- 插件页进入 Ctrl+K 命令面板（此前「侧栏有、面板搜不到」）。
- `theme.apply`：运行期切换宿主已注册的主题，不复用 `ui:theme` 的高风险授权。
- `requires_components`：插件可声明依赖的组件能力，接进运行前预检并给出安装提示。
- `plugins audit --local` 补上沙箱子进程**实跑**探测（此前只查平台能力）。

### 二、配置语法错误前置到 `validate`

| 输入 | 修前 | 修后 |
|---|---|---|
| JSONPath `$..x` | 静默误导航（返回非空但缺内容）| 报错并提示替代写法 |
| JSONPath 语法错 | 采集时才报 | `validate` 阶段报，点名字段 |
| CSS 选择器语法错 | 采集时才报 | `validate` 阶段报，点名字段 |
| 正则语法错 | **全程静默，字段恒空** | `validate` 阶段报，点名字段 |
| XPath 语法错 | 链接发现时才报 | `validate` 阶段报，点名键 |

判定一律复用引擎自己的解析器（`soupsieve` / `re` / `lxml` / 引擎分词器），
不另写一套「校验专用」语法检查——那样迟早出现「校验说行、运行说不行」。

同时修正 `source.kind: file` 的两处自相矛盾：

- `validate_config` 曾拒绝「有 `local_files`、无 `seeds`」的合法配置；
- `template_health` 曾拒绝同样合法的 file 模板。

两处现在与运行时口径一致，并新增首个 `kind: file` 模板 `generic/local-files`。

### 三、性能

- **抓取**：HTTP 连接复用（keep-alive）使 10 页任务 14.0s → 3.7s；
  同一页 HTML 只解析一次，单页 CPU 降 3.6 倍。
- **导出**：xlsx 改流式写出（8.19x）、CSV 去掉中间层、
  质量报告与证据查找不再重复解析同一行 JSON。
- **启动**：CLI `--help` / `status` / `capabilities` 与 GUI 冷启动均有明显缩短；
  校验器、抽取引擎、benchmark 等重模块改为按调用点惰性导入。
- **状态库**：为 responses / stage_checkpoints / 复核计数补索引，
  抓 5 万页时每页省 13ms，复核统计快 300 倍。
- **界面**：结果表翻页改字节偏移 seek（第 100 页 106.7ms → 3.9ms）、
  可执行文件探测与选择器编译加缓存。

### 四、静默失败清理

- 运行诊断此前恒返回空（调了一个不存在的方法）；
- 契约 1 审批绕过此前完全静默；
- keep-alive 路径此前不跟随重定向、不携带 cookie（登录任务直接失效）；
- 记录 ID 撞车导致记录静默丢失；
- 站点识别多处误判（散文里提到某框架、导航搜索框、文档提到 `application/json`）；
- 插件面板尺寸上限收紧（此前两个面板可把主窗口撑到 2332px）；
- 导航页补齐无障碍名（含三个内置容器页）。

### 五、工程质量

- 新增门禁：权限/能力白名单跨仓同集合、能力表 ⇄ 文档双向一致、
  声明式界面副作用通道与文档一致、组件 `provides` 域前缀归属、本地工具链版本同步。
- `tools/qa/` 补上内存快照与 CLI JSON 覆盖度体检；
  反向断言与测试洁净度检查成为常规流程。
- 文档同步：插件契约补充「声明式界面**不是**安全边界」的完整说明，
  明确它能消除什么、不能消除什么。

## 合规与诚实条款（固定字段，B14-💭-3）

- **不绕过**：本版本遵守 robots.txt、只采已获授权站点，不绕过验证码、付费墙、
  访问控制或站点安全策略；隐身/undetected 能力仅用于已授权站点并经 EgressBroker
  统一出口。
- **门禁不伪称**：外部门禁/审核状态如实标注 `pending`/`通过`，不伪称通过；
  无法本地验证的检查明确说明验证条件。

## 升级与回滚

- **升级**：直接替换即可。无配置迁移、无状态库结构变更、无资产格式变化。
  既有 `source.kind: file` 配置此前若被迫手抄 `seeds`，现在可以只留 `local_files`。
- **回滚**：1.2.0 与本系列早期版本可直接互换；便携版请整包替换，
  不要混用不同版本的 EXE、`_internal`、浏览器或运行时资产。
