# OmniCrawler 0.3.0 发布报告

> 发布日期：2026-08-01；配置协议：v5；公共 API：兼容。

## 发布结论

0.3.0 聚焦“第一次成功”的可用性与桌面生命周期可靠性：用户可以先用自然语言描述目标，首页集中收集试跑前必要信息，再进入可复核的细化流程。该版本不改变任务、工作区、证据或导出格式；安全边界与可恢复语义保持不变。

## 已交付改进

- 简单模式首页将自然语言任务描述提升为主输入，解析结果以可编辑任务草案呈现。
- 会阻止试跑的必填项集中到首页，减少向导后段才要求回填的中断。
- 右上角通知的自动关闭增加独立计时器兜底；关闭逻辑可重复调用。
- 页面转场在析构时停止动画，主窗口按取消、等待线程结束的顺序关闭；导出进度避免访问已销毁控件。
- 版本化离线构建继续复用已验证的本地环境与缓存，且不覆盖保留的 2.6.0 交付物。

## 验证与交付

- 发布前全项目基线：430 passed、3 skipped、1 warning；版本升级后需以本次构建执行记录为最终证据。
- 交付物：源码 ZIP、wheel、Windows Portable Standard ZIP、Windows Portable Full ZIP，以及各自完整的版本化暂存目录。
- 每个 Windows 构建均执行依赖矩阵检查、运行时清单、SBOM、便携冒烟和 ZIP 完整性检查；发行目录中的 `SHA256SUMS-0.3.0.txt` 是 ZIP 哈希的权威来源。

## 升级与回滚

- 从 2.0+ 升级继续使用现有迁移流程，配置协议保持 v5。
- 回滚前先退出 GUI/Worker 并备份工作区；不要将不同版本的便携目录组件混合复制。
- 2.6.0 产物作为保留版本继续可用；2.3.1 仅在 0.3.0 完整构建与校验成功后按明确授权清理。
