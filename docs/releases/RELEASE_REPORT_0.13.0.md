# OmniCrawler 0.13.0 发布报告

> 发布日期：2026-09-17；配置协议：v5；公共 API：兼容。

## 发布结论

0.13.0 是一次**判据与证据硬化**版本：把"优化做了没有"从**自述**变成**可复现的证据**。
不改变任务、工作区、证据或导出格式，安全边界与可恢复语义保持不变；
唯一的变化面是"**门禁更严、证据更硬**"。

核心交付：`quality` 门禁**首次全绿**；覆盖率基线按其真实数字收紧并加"只升不降"机检；
**离线可用**从静态预检升级为断网容器内的运行级验收；便携产物在**全新 runner** 上
解压已上传归档复跑（并因此抓到两个"构建期报绿、干净机器报红"的真缺陷）。

## 已交付改进

### 门禁可信（W1 / W6.2）

- 修 `worker` 的 `AF_UNIX path too long`：深工作区能正常起本地 worker（跨 ubuntu/macOS 复现的产品缺陷）。
- 修 convertx 基准缺可选后端时的行为：**自诊断 + CI 装 storage extra**，不再"该 skip 未 skip"。
- 回收 CI 覆盖率数字并按实测收紧基线：三平台 `all_source` **75.62–75.64%**、**TOTAL 76%**；
  6 项下限按「三平台实测最小值 − 2」上调（如 `all_source` 73.0 → **73.6**），
  并新增**只升不降**机检守卫（调低下限或**删除门禁**都判红）。
- `quality` 全绿（15/15 job），含三平台 `test`、`docker`、`gui-and-browser`。

### 离线可用（W3.4）

- 新增 `tools/offline_acceptance.py` + `quality.yml` 的 `docker run --network none`：
  **先证明"确实断网"**（任一外连成功即判红，否则整轮检查在空转）→ 从**本地**市场仓走
  `download_and_verify` **验签安装**（目录签名 + 防重放序号 + 包哈希 + 插件分离签名）→
  用产品 CLI 跑本地 fixture 样例（**记录数 == 真值**）→ 以"抓公网必失败"作负向对照。

### 便携产物可用性（W4.1 / W4.2）

- `release.yml` 的聚合 job 加 **tag 守卫**：手工派发只产出 artifacts、**不建 Release**。
- 新增 `portable-smoke` job：在**全新 runner** 上解压**已上传的归档**、用**包内入口**跑固定样例；
  `release.needs` 含它 ⇒ **产物不可用则不发布**。
- 由此抓到并修掉三个"构建期报绿、干净机器报红"的真缺陷：
  **① macOS 包内 tesseract 引用构建机的 `/opt/homebrew/Cellar/...` 绝对路径**
  （缺该 Homebrew 版本的用户机上 OCR 全坏）；
  ② PyInstaller 为 `nltk` 生成的**启动运行时钩子**让 app 一启动即崩（产品源码零引用 ⇒ 精确排除）；
  ③ `_ssl` 的 OpenSSL 依赖被解析到 cv2 自带的同名 `libcrypto` ⇒ 统一**钉到 `@loader_path`**。

### 判据与证据（W2 / W3）

- **取值位置契约化**：`core/field_value_source.py` 把"取值位置"的形状与键名收成单一真源，
  GUI 与核心校验同源 ⇒ 表单终于能建出「元素自身属性」规则（`selector=""` + `attr=href`）。
- **分页完整性判据**：「访问 N 页却只交付 M 条」必须**可见**；分页形状收成唯一契约，
  游标缺 `next_path` 从"静默只采一批"改为**加载时即报错**。
- **pdfx 基准扩三形态**（多页 / 表格 / 低质扫描，逐形态各自门槛不平均）+ **「页码等于真值页」**判据。
- **无头事件驱动懒加载定论**：平台能力已验收 + 产品动作的**已知限制**与位置轮询替代。
- **OCR 文本空白归一按来源默认生效**：OCR 页的文本值默认归一，原生文字层不动（**交付值变更**，见下）。

### 公网原场景复测（W5.1 / N1b）

`tools/public_retest.py`（受控执行、不进无条件 CI）三条判据实测：

- **重定向别名**：`http://iana.org/` 交付的 `source_url` **全部**是确认后的最终 URL
  `https://www.iana.org/`（**一个 URL 同时覆盖 apex→www 与 http→https**）。
- **同标题不同页面不误合并**：两页**各 10 条**，跨页重复作者未被合并。
- **取消↔恢复 == 不中断**：中断后 `resume` 到同一终点，**数据集一致**
  （40 条 / 4 来源，产品自报 `totals.records=40`）。

### 结构性项（W6）

- mermaid / echarts 许可正文随仓分发 + 机器守卫；审计 medium/low 按「影响正确交付」筛选复核（修 5 条）；
  mypy 严格范围扩到 `core`；等宽字体补 CJK 回退并**从"人工截图"改为机检**；
  基线记录带"输入快照 + 四维可比性"（不可比记录明确报出而非照平均值）；
  运行状态词表统一 + `--help` 段落顺序等小项。

### 桌面与体验

- **单页模式（详情页）不再静默丢短值**（旧实现一条 `len(text) < 5` 同时挡装饰又误伤数据）。
- 变更监测在关窗后不再留下在飞工作；`BackgroundWorker.cleanup()` 悬空钩子接线
  （三条路径、晚于终态、异常不改变任务终态）。
- GUI 表单可建列表 / API / 游标分页任务（含"分析页面并填字段"），从零建任务不再需要手写 YAML。

### 许可与打包

- 随仓 6 个字体补 `_shared/fonts/OFL.txt`（逐字上游文本 + 三家版权行）并补 NOTICES 声明；
  守卫**读字体 `name` 表**核对（改名骗不过）。
- `install_windows.ps1` 装依赖前校验解释器版本（此前可能选到 3.10/3.11，报错点离原因很远）。

## 验证与交付

- `quality` 门禁：**15/15 job 全绿**（三平台 `test`、`docker`、`gui-and-browser`、各类 install/lock job）。
- `release.yml`：三平台便携构建全绿；`portable-smoke` 三平台在**全新 runner** 上解压已上传归档复跑通过。
- 离线验收：断网容器内"装市场包 → 导入 → 跑本地样例"全流程成功，且抓公网必失败。
- 交付物：源码 ZIP / wheel / 各平台便携包（Standard + Full），以及各自完整的版本化暂存目录。
- 完整性：`SHA256SUMS-0.13.0.txt` 是各产物哈希的权威来源；SBOM / provenance 一并交付。

## 交付值变更（升级前请确认）

- **OCR 来源的文本值现在默认做空白归一**（`pages.parse_method == "ocr"` 时）。原生文字层不受影响，
  开关仍可显式关闭。若下游对 OCR 原始空白敏感，请在配置中显式关闭该归一。

## 合规与诚实条款（固定字段，B14-💭-3）

- **不绕过**：本版本遵守 robots.txt、只采已获授权站点，不绕过验证码、付费墙、
  访问控制或站点安全策略；隐身/undetected 能力仅用于已授权站点并经 EgressBroker 统一出口。
- **门禁不伪称**：外部门禁/审核状态如实标注 `pending`/`通过`，不伪称通过；
  无法本地验证的检查明确说明验证条件。
- 本版本的每项结论都附**可复现命令或提交号**；无法在本地验证的部分（容器内断网执行、
  真实便携产物内复跑）**明确说明交付给了 CI 判定**。

## 升级与回滚

- 从 0.12.x 直接覆盖升级即可；配置与工作区格式无变化（除上述 OCR 空白归一的默认值变更）。
- 便携包仍分 Standard（GUI + Chromium）与 Full（另含 ChromeDriver 与双 OCR 引擎）。
- 回滚：装回 0.12.x 即可；工作区与状态库向后兼容，无需迁移。
