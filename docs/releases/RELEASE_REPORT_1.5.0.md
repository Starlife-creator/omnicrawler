# OmniCrawler 1.5.0 发布报告

发布日期：2026-07-22

## 结果

1.5.0 完成“能力完整、操作收敛”的简单模式体验：首页可在一屏建立常见任务，系统解释每个自动决定并保留修改入口；复杂任务继续使用原五步向导。原专业/开发者模式、YAML、模板、录制、API、PDF/OCR、监测、调度、导出和复核能力均未移除。

帮助体系使用稳定 ID 和统一离线注册表，非显然控件覆盖率由自动测试保证为 100%。新增离线演示、结构化诊断、脱敏支持包、操作录制编辑、模板局部应用/撤销及无障碍配置。

## 本地验证证据

- Pytest：199 passed，2 skipped。
- Mypy：100 个源码文件，零错误。
- Ruff：全仓通过。
- GUI/帮助/简单模式组合回归：23 passed。
- 外部 Docker、跨系统 CI、签名 Standard/Full 便携包仍待相应环境执行，不声明为已通过。

1.6.0 将实现专业复核台、稳定/预览公共 SDK、插件 SDK 与受限独立进程，以及 AI 不可信输入边界和开发者检查工具。
