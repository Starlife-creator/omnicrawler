# 兼容与回滚

> 当前版本：2.6.0。本文件描述从 2.0+ 升级到 2.6.0 的兼容性策略。

## 兼容性保证

- 配置协议保持 v5，Task IR 和 SDK 兼容级别不变；2.0/2.1 工作区无需迁移。
- 公共 SDK（validate/compile/run/query）接口保持稳定；破坏性变更须 bump major。
- CLI 子命令语义、GUI 三种模式（简单/专业/开发者）保持稳定，不静默改变用户可见行为。
- 配置 schema 向后兼容：旧版配置经迁移脚本可升级到当前版本，不做破坏性丢弃。
- 任何 @deprecated 标记项保留至少一个 minor 周期并给出替代方案，再移除。
- 2.2.0 至 2.6.0 的优化不改变公共 API 或配置协议 v5 的语义；内部实现持续采用持久事件循环、DB 批量操作和连接池化。
- 2.6.0 的本地 E2E 与发布一致性检查仅增加验证，不改变用户任务、工作区或产物格式。

## 视觉偏好

新视觉偏好存入现有 QSettings；2.0 会忽略新增的色盲/减少动画/缩放偏好，不影响任务。

## 回滚

- 回滚到旧版前退出 GUI/Worker 并复制工作区；证据、Schema、复核和任务配置均可继续使用。
- 旧版不理解的新字段仍按未知字段策略保留或忽略。
- SQLiteRunRepository 已标记 DeprecationWarning，回滚到 2.0 仍可用，但建议逐步迁移到新 Repository 接口。
