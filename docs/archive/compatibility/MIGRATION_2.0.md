# 从 1.0/1.1 迁移到 2.0

1. 退出旧版本，复制完整项目/便携目录并校验备份。
2. 在 2.0 使用"导入任务"或 `omnicrawler migrate --dry-run` 先看配置 v1→v5 差异。
3. 选择工作区数据模式；迁移器先生成快照，失败自动回滚，未知字段进入无损保留区。
4. 运行系统体检、计划编译和三页试跑；只有计划哈希一致才继续正式运行。
5. 检查插件权限、AI Provider、凭据引用、Schema 契约和敏感字段摘要。

回滚：停止 Worker，复制回迁移前快照/完整备份；不要只回滚数据库而保留新证据目录。2.0 不覆盖旧原始证据，配置历史和运行清单可定位回滚点。
