# 低门槛使用指南

> 适用版本：0.13.1 · 配置协议：v5 · 维护状态：现行

GUI 默认进入“简单模式”，技术配置不会丢失，只是隐藏。普通用户先在第一步用自然语言描述目标（也可直接填写网址）；系统会把入口、范围、主题、附件/PDF、变化监测和结果格式汇总到同一页。其余页面只在需要时用于微调：

1. 描述需求、确认入口网址与系统建议；保留“自动识别（推荐）”即可开始。
2. 仅在有多个入口、特殊分页或性能要求时补充范围。
3. 需要精确字段时添加；不添加时自动提取标题、正文和来源。
4. 仅在需要排除词、OCR、输出目录或 AI 时细化处理。
5. 查看业务摘要，先试跑 3 页，再保存或运行。YAML 默认折叠。

专业用户可以切换“专业模式”编辑 YAML；开发者切换“开发者模式”查看完整诊断和插件能力。三种模式使用同一配置，不会产生互不兼容的项目。

常见错误会提供建议。详细请求错误位于工作目录的 `diagnostics`，任务结果、原始文件和 PDF 产物仍沿用既有的目录结构。

## 文件转换的结果与取消

转换完成后查看实际写入行数。有坏行被跳过、记录超出输出上限或单元格被截断时，结果会显示异常提示；详情中提供数量和部分问题位置。容错转换仍可完成，命令行需要遇到解析错误立即停止时可使用独立转换入口的 `--on-error abort`。

点击取消后，界面等待当前操作安全结束，再显示已取消；第三方文档解析或文件打包可能需要等待更久。内置转换在提交前取消或失败时保留已有输出；如果最终提交已经开始，则显示实际完成结果。任务结束并清理后可再次运行。

## 已保存任务的模板、分析与恢复

在“设置 → 模板、交付分析与恢复”打开任务工具。先保存当前编辑。成功试跑摘要可保存为模板；复用新参数仍需验证和试跑，历史结果不会批准新任务。

选择交付清单后读取文档列表，明确勾选再分析；支持格式 1 JSON 清单和公开 PDF 下载生成的已验证 JSONL 清单。分析默认只生成本地事实，文字型 PDF 引用带页码。只有勾选使用 AI 且配置隐私/预算允许时才发送所选文档摘录；暂停会保留本地事实，模型解释需要人工审阅。

读取失败列表后只勾选需要重试的请求，确认后重入队；再回任务页恢复运行。认证过期项目不能直接重试，应先在登录会话页验证。规则修复先选择本地候选和独立证据预览，证据或候选变化后重新预览，再确认应用；之后可以使用新证据观察或回滚。操作期间不切换任务，关闭工具会等待后台结束，已经提交的结果保留在原任务。
