# OmniCrawler 2.0.0 发布候选报告

## 交付范围

2.0 以桌面专业版为主线，同时提供能力完整的简单模式和可成长的公共 SDK/插件平台。五步向导、问号帮助、模板、操作学习、API发现、PDF/OCR、监测、定时、导出和复核全部保留并演进。

安全、运行恢复、IR、独立 Worker、工作区/便携、帮助与无障碍、专业复核、插件隔离、AI边界、证据账本、数据契约、时态事件、影子修复、自适应执行、语料和 RC 控制面已在 1.2–1.9 分阶段实现。

## 当前验证结论

- 216 passed，2 skipped；120 个源码文件 Mypy 零错误；Ruff 与 compileall 通过。
- 安全/状态 89.47%、管线/HTTP/来源 75.05%、PDF/OCR 66.97%、桌面核心 69.12% 达到各自门禁。
- 总覆盖率 67.11% 未达到路线定义的 GA 70%；浏览器/API 69.92% 也低于 70%。因此该节点是完整源码候选，不伪称全部 GA 门禁通过。
- 正式代码签名、跨系统托管 CI、物理三档 Benchmark、长稳和干净机 Standard/Full 仍需外部发布环境。

2.1 将在保持 2.0 能力的基础上完成视觉与交互优化，并补齐上述本机覆盖率门禁后生成最终新版制品。
