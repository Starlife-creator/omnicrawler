# OmniCrawler 1.6.0 发布报告

1.6.0 完成桌面专业版复核工作流和开发者平台第一版公共契约。桌面仍是主线；GUI、CLI 和第三方调用共享 ApplicationService、Task IR 与 TaskPlan。公共 SDK 的稳定/预览状态可机器读取，数据查询不泄漏数据库实现。

插件运行已具备独立进程、最小环境、受限权限、超时终止和失败隔离；签名的真实发行验证仍需正式证书环境。AI 页面/PDF/API内容统一按不可信输入处理，输出先过确定性 Schema，低置信结果留给复核台。

本地证据：204 passed、2 skipped；108 个源码文件 Mypy 零错误（修正一处显式类型后复验）；Ruff 通过。Docker、跨系统 CI、正式代码/插件签名与最终便携包保持待外部环境验证。
