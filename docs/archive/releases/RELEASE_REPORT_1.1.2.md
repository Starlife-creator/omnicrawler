# OmniCrawler 1.1.2 发行与验收报告

发行日期：2026-07-21

## 版本定位

1.1.2是从1.1.0走向2.0.0路线中的质量与兼容性基线版本。它不改变配置协议v5和插件API v1，
重点是把此前被覆盖率配置排除的桌面、PDF/OCR、应用入口、浏览器和协议模块纳入真实全源码统计，
并建立可执行的子系统门禁。

## 完成内容

- 配置v1至v5迁移、未来协议拒绝、迁移文件保护、未知字段往返和配置历史恢复进入回归集；
- 模板推荐、渲染、差异、三方合并、导入导出和验证进入CLI与函数级契约测试；
- 通用HTML、API、Sitemap、Feed、附件、媒体、分页、SSE、WebSocket、Redis、Scrapy和异步HTTP
  进入离线协议测试；
- Playwright、Selenium、浏览器池、动作列表、API捕获与脱敏进入双层测试；
- PDF核心命令、运行时诊断、OCR分支和人工复核CSV/XLSX路径进入回归；
- CI生成全源码JSON覆盖率并执行总量和五组关键子系统阈值。

## 本版本修复

1. 模板三方合并在删除字段时不再深拷贝内部缺失值哨兵，避免不可序列化对象泄漏；
2. Playwright和Selenium动作执行器会依次尝试`selectors`推荐列表，不再只接受单个`selector`；
3. 配置历史快照嵌入纳秒顺序键，修复一秒内连续保存时最新版本识别和裁剪顺序不稳定。

## 兼容性

- Python 3.10+；
- 配置协议保持v5，v1至v4继续自动迁移；
- 插件API保持v1；
- GUI读取、编辑和保存时继续保留未知顶层与扩展字段；
- 1.1.0和1.1.1工作区无需破坏性迁移；
- 旧格式配置历史快照继续按文件时间排序，新格式使用内嵌纳秒顺序。

## 外部门禁与已知边界

- 当前本机没有Docker命令，因此固定digest的Dockerfile仍须由Docker CI实际构建；
- Standard/Full Windows便携包尚须在目标构建机生成，并在干净Windows账户执行原生运行时验收；
- 多操作系统、多Python版本矩阵已写入CI，但本报告只把本机实际执行结果标为通过；
- 真实站点授权、反自动化规则、OCR业务准确率、长稳和高并发必须使用获授权样本另行验收；
- 1.2.0将继续实施统一Egress Broker和运行可靠性，不把1.1.2回归基线误称为2.0完成。
