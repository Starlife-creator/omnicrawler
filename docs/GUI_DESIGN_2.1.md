# OmniCrawler 桌面视觉与交互规范（0.11.0）

## 原则

1. 功能优先：美化不隐藏原有入口，不删除字段问号、F1 帮助、模板、录制和专业能力。
2. 渐进呈现：简单模式默认给出完成任务所需的全部主路径；专业参数与开发者接口按需展开。
3. 本地可靠：背景由 Qt 本地绘制，不依赖网络图片；动效不阻塞抓取 Worker。
4. 可访问：信息不能只靠颜色表达，键盘焦点必须可见，减少动画与高对比度立即生效。

## 0.11.0 首次成功路径

- 首页以用户的自然语言任务描述为主输入；解析结果必须显示为可修改的任务草案，不能把推测当作已确认事实。
- 所有会阻止开始试跑的必填信息集中在第一页，并在同一视野内说明用途、默认值与错误修复方式；后续页面只承载高级细化和复核。
- 通知应在可预期时间自动消失。动画回调只能改善体验，不能成为清理通知的唯一机制；计时器兜底和幂等关闭是必需保护。
- 页面、对话框和后台任务的对象所有权清晰：关闭窗口先请求取消，再等待工作线程停止；转场动画停止后才释放页面引用。

## 设计系统

- 主题：明亮、暗色、高对比度、色盲友好，共用语义令牌。
- 字体缩放：80%、90%、100%、110%、125%、140%、160%，重复切换不累计误差。
- 动效：160ms 页面淡入、柔和状态呼吸和低频首页光晕；减少动画时全部停用。
- 层级：首页主任务、快速卡片、业务入口和导航采用明确间距与阴影，不用过量装饰。
- 状态：成功、警告、失败同时提供文字、图标/形态和颜色线索。

## 验收清单

- Tab/Shift+Tab 可遍历主要控件，Enter/Space 可触发按钮；
- F1 打开帮助中心，字段问号保留上下文；
- 主题与字体变化后主窗口、帮助栏和状态控件一致；
- 减少动画后没有持续计时器造成的视觉运动；
- 低分辨率和 160% 缩放下主流程仍可滚动、无功能被裁掉；
- 无网络状态下背景、图标、帮助和简单模式可正常使用。
- 首次进入简单模式时，用户可在第一页完成描述、目标、范围、输出与运行前确认；不会在后续“下一步”才被要求回填关键输入。
