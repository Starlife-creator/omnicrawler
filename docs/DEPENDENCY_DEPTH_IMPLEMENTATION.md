## 已完成的实际验证

本机真实 Chromium 验证延迟数据与虚拟列表；真实 Crawl4AI 执行离线 Markdown/CSS 提取，并在处理时禁止 socket 连接；真实 Scrapy 离线 spider 验证有效 JSONL 交付。新增核心守卫均做旧实现反向失败和候选字节恢复。

最终单元回归通过；凭据修复后重新验证相关消费者，最终集成回归通过。发现的凭据后端静默丢弃写入问题已修复：确认主密钥持久化后才采用，失败时走受保护的回退路径。扫描 PDF 验收保留真实字段真值，并按实际区域识别分验证复核状态，未降低产品放行阈值。原生浏览器保留桥接声明的视口尺寸，非法尺寸在创建上下文前拒绝。

后续完整性优化：虚拟列表同时声明结束标记和预计数量时，两项均须满足。数量不足或超出明确标为部分结果，避免不完整发现进入后续删除比较；真实浏览器管线覆盖正常数量与终点数量不符的场景。

2026-10-08 复核闭环：在结果列表进入证据查看器后，可打开重提取候选复核，显式选择对应候选、查看字段与来源证据差异并填写理由。接受替换本条完整数据与候选证据，拒绝保留当前值；保留人工编辑历史及独立决定审计。缺失字段与 null 分别显示，未知置信度不默认为 100%。陈旧快照、候选重复映射及重复决定被拒绝，决定与审计在同一数据库事务提交。新候选生成前保存上一代候选及决定历史。接受候选不清除其已有质量问题。

该入口不自动匹配、增加或删除记录，也不发送通知或更新已有导出文件；尚未映射的候选明确留在检查点中。质量汇总、观察和版本记录仍属于原采集快照，本条复核变更由编辑历史与决定审计记录，不能作为一次新的采集运行。

2026-10-08 时间事件通知：显式字段映射在真实状态库通知路径生成事件解释，并可按事件类型抑制通知。字段缺失与 null 分离，时区等值和声明金额单位等值不制造业务变化；保留确认、冷却、任务范围和原始观察。此映射不推断未知生效时间、不自动合并实体、不根据网页删除推断撤回，未实际向外部地址发送通知。

2026-10-08 重处理保护：保存受保护候选前应用同一字段契约、阈值、唯一性与异常评估，不累加正式质量汇总；无契约候选明确为未评估。接受候选仍保留其质量问题。归档在派生结果重置前逐一验证正文摘要，提取读取时再次验证；预检摘要不一致不会清除现有记录。预检之后的文件变化会报错，不保证整个重处理过程在所有故障下原子回滚。

2026-10-08 AI 表格上下文：同章节的多张平面表格分别分块，各自重复本表表头与短表题，避免第一张表的标签或单位传播到后续表格。嵌套表格不重复猜测表头。长度与原文覆盖守卫使用确定输入验证；超长行和跨页语义仍不宣称已完全解决。

2026-10-08 来源级局部重处理：reprocess --record-id 只重新计算本记录所属响应，保留同来源原记录与所有其他来源，产生显式待复核候选；不重置全运行、不刷新导出、不生成变化通知。最新响应必须存在匹配正文摘要的有界归档，304 只复用同摘要归档。该能力是手动选择来源级增量，不是自动依赖失效分析或字段级增量引擎。

2026-10-08 跨平台故障守卫：下载 CI 诊断确认，进程池故障测试仍模拟旧的后端创建入口，缺少 Paddle 的核心安装会先在轻量预检退出。测试改为模拟实际预检入口，不放宽已完成页、未完成页和崩溃原因的断言；模拟 Paddle 包缺失时完成反向验证。证据查看器按数据库质量状态显示待复核或未评估，避免显示零风险。

复用现有质量基准，在可控本地页面与生成的 PDF 上执行实际管线。以下是当前实现的一次本机测量，不是旧版本对照，也不是普遍性能承诺。内存统计包含主进程与子进程，模块热加载与执行次序会影响读数。

## 能力边界与外部验收条件

- 最初验收未定位完整 Paddle 缓存，富输出适配、坐标来源和生命周期使用可控输出验证。2026-10-08 后续在项目运行时缓存定位常用模型并完成真实 CPU 文字探针，见下文；仍未报告完整表格、GPU/多进程性能或真实业务准确率。
- 没有业务方批准的困难资料和留出真值，自动放行阈值尚未按真实站点、时间片或 OCR 引擎校准。识别分、自报分和规则分均不是正确概率。
- 旋转、裁剪、展平的原图变换缺失时明确声明未知，未生成猜测的 PDF 叠加框。唯一文字区域映射也不证明业务语义归属完全正确。
- 超长表格行可能仍需有界拆分；AI 原文支持只证明候选值出现在引用中。不同主体、单位换算和跨页表格仍须结合任务规则与复核。未发起真实模型请求。
- 胶囊默认关闭，启用后受容量和保留期限限制；本地哈希校验只能发现与已知摘要不一致，不能证明本地不可篡改。
- Scrapy 是受信任外部执行，不具备原生质量、通知、证据和断点恢复语义。Crawl4AI 自治联网、隐匿与第三方 LLM 路径被明确拒绝。
- 三平台构建、便携包和完整 GUI 工作流仍按仓库要求留在 CI 与发布验收；本轮不把单元级 Qt 验证称为完整 GUI 用户验收。

运行证据位于工作区 `user-test-runs/dependency-depth-implementation-20261007/`：各批静态门禁、反向守卫、最终回归 XML 与 `quality-resource-measurements.json`。失败尝试保留用于说明环境限制和修复过程，不覆盖为通过记录。

## 召回优先的开发验收与错误边界（2026-10-08）

维护者明确选择优先减少漏采，允许更多误报由人工复核。质量失败用于标记与解释，不应静默丢弃已经提取的候选；范围、robots、凭据和资源预算仍须执行。提高复核阈值本身不能发现完全没有进入候选集的记录，不能把字段完整度当成站点覆盖率。

通用记录管线默认 `extract.review_policy: recall`。非必填字段缺失同样进入复核；无法核对的字段证据明确标为未评估或不支持。质量元数据保存 `missing_fields` 和每个配置字段的 `field_checks`，证据查看器显示未提取字段，不伪造空值或置信度。`contract` 可用于明确接受可选字段缺失的任务，已有冲突和值/标签错配仍要求复核。SDK 直接调用 `assess_record(s)` 时须显式传 `review_policy="recall"`；不把规则分称为正确概率。整数类型的上下界与其他数值类型一样生效。

### 检查目录与处理规则

以下是开发与任务配置的检查目录，包含已实现守卫和待验证语义；不是宣称所有检测已自动化。没有业务分布时不编造统一的准确率、OCR 分数或异常阈值。已实现项沿用实际契约和配置，证据不足项进入复核或标为未知。

| 范围 | 应检查的错误边界 | 当前处理与限制 |
|---|---|---|
| 入口 | 种子为空、错误来源类型、损坏配置、未知策略 | 配置校验；非空可执行入口才可验收 |
| 出口范围 | 域名、协议、端口、重定向、robots、私网、凭据越界 | 拒绝并留诊断；召回偏好不突破授权范围 |
| 抓取 | 超时、限流、HTTP 错误、重试耗尽、响应超限 | 有界重试和错误记录；失败不能算覆盖完成 |
| 页面发现 | 深度/页数预算、过滤拒绝、重复请求、链接未跟随 | 发现步骤保存计数和停止原因；未证明整个站点覆盖 |
| 动态页面 | 延迟数据、分页终点、预计数量、虚拟列表移除、动作失败 | 数量与终点守卫、保留已发现项；预算用尽标部分 |
| API | 游标未进展、响应格式错误、分页重复、空页与真正终点 | 分页契约与诊断；业务预计总量需来源声明 |
| PDF 输入 | 加密、损坏、缺页、解析失败、OCR 失败/取消 | 独立页状态；未完成页不得冒充已处理 |
| 文本层 | 无字、乱码、少量页眉掩盖图片、图片混合页面 | 现有字符/乱码/图片比例判据；较小嵌图漏字仍需验证 |
| OCR | 低清晰度、旋转、裁剪、展平、缺模型、算子失败 | 引擎错误保留；坐标变换未知明确标未知 |
| 表格 | 合并单元格、多表表头串用、单位脚注、跨页、嵌套、超长行 | 富结构与本表上下文保留；跨页/嵌套语义未全自动解决 |
| 字段存在性 | 必填、条件必填、可选缺失、缺失与 null、0/False、允许空值 | 逐字段清单；recall 缺失复核；合法 nullable/allow_empty 按契约 |
| 字段形态 | 整数/小数/金额、日期、枚举、正则、长度、上下界 | 严格字面量与契约校验；原候选不因校验失败而消失 |
| 交叉字段 | 相等/不等、数值大小、身份/期间、不同主体 | 显式关系校验；主体/期间归属不能仅凭字符串出现保证 |
| 来源证据 | 原文匹配、URL、标签、清洗前值、冲突、未知识别分 | 确定性核对；recall 未验证也复核，分数不是正确概率 |
| 单位与时间 | 货币、倍率、时区、截止时间、生效时间、负面语句 | 只按显式映射解释；未知不猜，原值与事件理由保留 |
| 重复与身份 | 近似重复、同值不同主体、身份字段缺失、跨任务串用 | 近似重复只标记复核；显式存储去重可能合并同身份，任务须检查 identity/deduplicate_by |
| 异常分布 | 离群值、不同业务组、冷启动、恒定多数 | 分组 MAD/显式 zscore；不足样本标证据不足，不据此删记录 |
| AI | 无密钥、未支持字段、无原文支持、冲突、截断、超预算 | 默认禁用；确定性路径可用；模拟响应只验证协议，不充当真实模型能力 |
| 增量与历史 | 304、部分发现、归档损坏、配置变化、人工值覆盖 | 摘要校验、候选保护和来源级重算；自动字段依赖失效仍待开发 |
| 复核 | 未提取项隐藏、未知分当满分、候选重复映射、陈旧决定 | 显式显示、拒绝非法决定、事务审计；接受不掩盖原质量问题 |
| 通知 | 首轮基线、误撤回、金额等值、确认/冷却、发送失败 | 保留原始变化与抑制原因；具体通知策略需任务声明 |
| 导出 | 未评估记录、证据丢失、人工更新未重导出、结果容量截断 | 当前值与质量/来源可检查；既有文件不会随复核自动刷新 |
| 发布验收 | 空测试集、未知字体截图、源码与 CI 不同、资源/便携差异 | 非空断言、固定源码同环境视觉比较、实际产物单独验收 |

### 公开项目参照与无密钥验证

[Docling](https://docling-project.github.io/docling/concepts/confidence_scores/)将 OCR、布局与解析质量分开，并提供页面级报告和低质量区域摘要；其文档还明确 table_score 尚未实现。这里借鉴分项与问题区域展示，不照搬分数为业务正确概率。[Unstructured](https://github.com/Unstructured-IO/unstructured/blob/main/unstructured/partition/strategies.py)按文本层和依赖可用性切换策略，无法处理时显式失败；自动回退也不代表保留了原策略的表格能力。

[PubTabNet](https://github.com/ibm-aur-nlp/PubTabNet)公开例图及单元格/HTML 标注可作为开发真值。例图不是留出业务集，文字 token 多重集覆盖忽略阅读顺序、单元格归属和表格拓扑。诊断在工作区保留固定上游提交、输入摘要、原始输出和未覆盖 token；不将公开例图重新分发进产品。标注许可为 CDLA-Permissive-1.0，原图须遵守原 PMC 文章许可。

本机依赖包和项目 `.runtime/models/paddlex/official_models` 已齐备常用 OCR/布局/表格模型；仅查看用户缓存会漏掉这份缓存。实际 CPU 推理发现当前 oneDNN 路径存在未实现算子，适配层新增 `ocr.enable_mkldnn`，默认 false；true 必须显式启用并实测。禁用加速不保证所有引擎/模型/设备都可用，性能需同输入另测。无需 AI 密钥的验证使用实际 Tesseract/Paddle 与确定性提取，不生成假密钥，也不将固定模拟响应包装成 AI 服务。

同一生成文字图片在普通 CPU 推理下实际识别出预设编号、金额与币种，修复前 oneDNN 未实现算子异常的日志和修复后输出分别保留。该探针关闭表格、方向与展平，不证明完整文档能力。公开表格例图的实际 Tesseract 文字覆盖诊断也已运行，暴露无可用文本与大量未覆盖 token；失败与遗漏保留，不改称通过。这说明依赖可运行并不等于困难资料已充分识别，后续应据这些遗漏逐场景验证，而非下调产品阈值。
