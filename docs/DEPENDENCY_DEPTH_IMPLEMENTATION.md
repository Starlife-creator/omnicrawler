## 已完成的实际验证

本机真实 Chromium 验证延迟数据与虚拟列表；真实 Crawl4AI 执行离线 Markdown/CSS 提取，并在处理时禁止 socket 连接；真实 Scrapy 离线 spider 验证有效 JSONL 交付。新增核心守卫均做旧实现反向失败和候选字节恢复。

最终单元回归通过；凭据修复后重新验证相关消费者，最终集成回归通过。发现的凭据后端静默丢弃写入问题已修复：确认主密钥持久化后才采用，失败时走受保护的回退路径。扫描 PDF 验收保留真实字段真值，并按实际区域识别分验证复核状态，未降低产品放行阈值。原生浏览器保留桥接声明的视口尺寸，非法尺寸在创建上下文前拒绝。

后续完整性优化：虚拟列表同时声明结束标记和预计数量时，两项均须满足。数量不足或超出明确标为部分结果，避免不完整发现进入后续删除比较；真实浏览器管线覆盖正常数量与终点数量不符的场景。

2026-10-08 复核闭环：在结果列表进入证据查看器后，可打开重提取候选复核，显式选择对应候选、查看字段与来源证据差异并填写理由。接受替换本条完整数据与候选证据，拒绝保留当前值；保留人工编辑历史及独立决定审计。缺失字段与 null 分别显示，未知置信度不默认为 100%。陈旧快照、候选重复映射及重复决定被拒绝，决定与审计在同一数据库事务提交。新候选生成前保存上一代候选及决定历史。接受候选不清除其已有质量问题。

该入口不自动匹配、增加或删除记录，也不发送通知或更新已有导出文件；尚未映射的候选明确留在检查点中。质量汇总、观察和版本记录仍属于原采集快照，本条复核变更由编辑历史与决定审计记录，不能作为一次新的采集运行。

2026-10-08 时间事件通知：显式字段映射在真实状态库通知路径生成事件解释，并可按事件类型抑制通知。字段缺失与 null 分离，时区等值和声明金额单位等值不制造业务变化；保留确认、冷却、任务范围和原始观察。此映射不推断未知生效时间、不自动合并实体、不根据网页删除推断撤回，未实际向外部地址发送通知。

2026-10-08 重处理保护：保存受保护候选前应用同一字段契约、阈值、唯一性与异常评估，不累加正式质量汇总；无契约候选明确为未评估。接受候选仍保留其质量问题。归档在派生结果重置前逐一验证正文摘要，提取读取时再次验证；预检摘要不一致不会清除现有记录。预检之后的文件变化会报错，不保证整个重处理过程在所有故障下原子回滚。

2026-10-08 AI 表格上下文：同章节的多张平面表格分别分块，各自重复本表表头与短表题，避免第一张表的标签或单位传播到后续表格。嵌套表格不重复猜测表头。长度与原文覆盖守卫使用确定输入验证；超长行和跨页语义仍不宣称已完全解决。

## 能力边界与外部验收条件

- Paddle 完整推理模型未在本机齐备：未下载模型，未报告 Paddle 真实准确率或 GPU/多进程性能。其富输出适配、坐标来源和生命周期使用可控输出验证。
- 没有业务方批准的困难资料和留出真值，自动放行阈值尚未按真实站点、时间片或 OCR 引擎校准。识别分、自报分和规则分均不是正确概率。
- 旋转、裁剪、展平的原图变换缺失时明确声明未知，未生成猜测的 PDF 叠加框。唯一文字区域映射也不证明业务语义归属完全正确。
- 超长表格行可能仍需有界拆分；AI 原文支持只证明候选值出现在引用中。不同主体、单位换算和跨页表格仍须结合任务规则与复核。未发起真实模型请求。
- 胶囊默认关闭，启用后受容量和保留期限限制；本地哈希校验只能发现与已知摘要不一致，不能证明本地不可篡改。
- Scrapy 是受信任外部执行，不具备原生质量、通知、证据和断点恢复语义。Crawl4AI 自治联网、隐匿与第三方 LLM 路径被明确拒绝。
- 三平台构建、便携包和完整 GUI 工作流仍按仓库要求留在 CI 与发布验收；本轮不把单元级 Qt 验证称为完整 GUI 用户验收。

运行证据位于工作区 `user-test-runs/dependency-depth-implementation-20261007/`：各批静态门禁、反向守卫、最终回归 XML 与 `quality-resource-measurements.json`。失败尝试保留用于说明环境限制和修复过程，不覆盖为通过记录。
