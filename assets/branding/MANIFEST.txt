OmniCrawler branding assets
==========================

Everything here is generated: the SVGs from one set of geometry constants, every PNG
from its own SVG, and the icon containers from those same PNGs. Rebuild -- and re-lay
the files into the repositories -- with
`python work/build_branding.py --layout repo --repo-root <main repo> --market-root <market repo>`.

Paths are repository-relative. The runtime copy under
`src/omnicrawler/gui/branding/` is what the application loads; the rest lives under `assets/branding/`.

Each raster line names the SVG it was rendered from; `verify_branding.py --repo` fails
if a raster and its source disagree about the frame, or if a PNG has no declared source.

Icon containers:
- omnicrawler.ico carries 7 frames: 16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256
  sizes below 48 come from the small tier, 48-64 from the medium tier, 128+ from the master.
- omnicrawler.icns carries 11 chunks: icp4, icp5, icp6, ic07, ic08, ic09, ic10, ic11, ic12, ic13, ic14
  ic11-ic14 are Apple's @2x partners of icp4/icp5/icp6/ic07.
- assets/branding/web/favicon.ico is a separate, smaller container (16/32/48) so pages do not
  have to pull the full Windows icon.

Design:
- Dark green: #0F3D2E
- Light mint: #EAFBE8
- Mint: #DFF7E4
- Accent: #5DCAA5
- Green: #1D9E75

Concept:
- Radar/network = discovery and coverage
- Hexagon = platform core / structured system
- Four four-point stars = omni-directional capability and a subtle Starlife signature
- Flow line = data/pipeline, with no spider/bug imagery

Lettering is stored as outlines, so no renderer can substitute a different font.
