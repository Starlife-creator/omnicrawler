# 扩展文件来源说明

本目录中的浏览器扩展文件仅供开发/测试用途随仓库分发，来源与许可如下：

| 文件 | 来源 | 许可证 | 说明 |
|------|------|--------|------|
| `EasySpider_en.crx` | EasySpider 项目（https://github.com/NaiboWang/EasySpider） | AGPL-3.0 | 英文版；自动化录制脚本扩展，供采集测试使用 |
| `EasySpider_zh.crx` | 同上 | AGPL-3.0 | 中文版；同上 |

## 变更记录（2026-08-10）

- **移除 `XPathHelper.crx`**：该扩展来自 Chrome 应用商店，为**专有软件**，
  无再分发许可，随仓库分发构成版权风险（审查报告 S43）。
  需要此功能的用户请自行从 Chrome 应用商店安装。
