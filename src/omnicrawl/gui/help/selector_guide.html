🔍 OmniCrawler GUI — 选择器语法帮助

选择器是爬虫配置的核心。OmniCrawler 支持三种选择器语法：CSS 选择器、XPath 和 JSONPath。

1. CSS 选择器快速参考

语法说明示例
.class按 class 名称选择.title → 选择 class="title" 的元素
#id按 id 选择#main → 选择 id="main" 的元素
[attr]按属性选择[href] → 选择有 href 属性的元素
[attr=value]按属性值精确匹配[data-type="news"]
parent child后代选择器#main a → #main 下所有链接
parent > child直接子元素ul > li → ul 的直接 li 子项
:nth-child(n)第 n 个子元素tr:nth-child(2) → 第二行
:first-child第一个子元素li:first-child
:last-child最后一个子元素li:last-child
:contains(text)包含文本（jQuery 扩展）部分解析器支持

真实示例

# 新闻列表中的标题链接
.news-list .item-title a

# 所有 PDF 下载链接
a[href$=".pdf"]

# 表格中第二列的内容
table.data-table td:nth-child(2)

# 公告列表中第一个 h3 标题
.announcement-list h3:first-child
💡 提示：在浏览器中按 F12 打开开发者工具，右键目标元素选择"Copy → Copy selector"可直接复制 CSS 选择器。

2. XPath 快速参考

语法说明示例
//tag选择所有 tag 元素//a → 所有链接
/tag从根开始的直接路径/html/body/div
[@attr]有某属性的元素//a[@href]
[@attr='val']属性等于某值//div[@class='title']
[contains(@attr,'val')]属性包含某值//a[contains(@href,'/news')]
[text()='val']文本精确匹配//span[text()='公告']
[contains(text(),'val')]文本包含某值//h2[contains(text(),'新闻')]
[starts-with(@attr,'val')]属性以某值开头//a[starts-with(@href,'https://')]
[position()=n]第 n 个元素//li[position()=1]
/text()获取文本内容//h1/text()
/@attr获取属性值//a/@href
parent::tag父元素//a/parent::div

真实示例

# 所有 class 包含 'title' 的 div 中的第一个链接
//div[contains(@class,'title')]/a[1]

# 文本内容为"下一页"的链接
//a[contains(text(),'下一页')]

# 获取所有新闻标题的文本
//div[@class='news-item']//h3/text()

# 所有 PDF 文件的链接地址
//a[contains(@href,'.pdf')]/@href
💡 提示：在浏览器开发者工具中，右键目标元素选择"Copy → Copy XPath"可获取 XPath。但浏览器生成的 XPath 通常较长，建议手动优化。

3. JSONPath 快速参考

语法说明示例
$根对象$
.key访问属性$.data
..key递归搜索$..title → 任意层级的 title
[n]数组索引$.list[0] → 第一个元素
[*]所有数组元素$.data.list[*].title
[?(@.key=='val')]过滤条件$..items[?(@.price<100)]
[start:end]数组切片$.list[0:10]

真实示例

# REST API 返回数据中的所有标题
$.data.items[*].title

# 递归搜索所有 author 字段
$..author

# 过滤价格小于 100 的商品名
$.products[?(@.price<100)].name

# 获取列表前 5 条
$.data.list[0:5]
💡 提示：JSONPath 适用于 REST API 数据源。使用 JSONPath Online Evaluator 可在线测试表达式。

4. 常见错误及解决方案

❌ 选择器因页面动态渲染失效
症状：CSS/XPath 选择器在浏览器中有效，但爬虫返回空结果。
解决：切换到"动态浏览器"数据源类型，使用 Playwright 渲染 JavaScript。
⚠ 选择器语法错误
症状：运行时报错 "Invalid selector" 或 "XPath error"。
解决：使用 Step 3 中的"测试选择器"功能，验证选择器在真实页面上的表现。
❌ 选择器匹配过多或过少元素
症状：提取结果包含不需要的内容，或遗漏需要的内容。
解决：增加父级上下文限制范围。例如用 .article-body p 替代 p。
⚠ 命名空间问题（XPath）
症状：某些 XML 文档中使用命名空间前缀，XPath 匹配失败。
解决：使用 *[local-name()='tagName'] 忽略命名空间，或使用 CSS 选择器替代。
