# OmniCrawler GUI 工作台 — 版本变更记录

> **版本说明**：以下 v8.0 记录来自项目采用语义化版本（semver）之前的内部开发快照。
> 自 OmniCrawler 1.0.0（2026-07-18）起，GUI 随主项目统一使用语义化版本号，
> 详见项目根目录 `CHANGELOG.md` 和 `RELEASE_REPORT_*.md`。

## v8.0 (2026-07-17) — 内部开发快照

### 新增功能

- 完整的 PyQt6 GUI 工作台，涵盖爬虫配置全生命周期
- 五步配置向导（网站类型 → URL → 字段 → 下载 → 预览）
- 高级 YAML 编辑器，支持语法高亮、双向同步、差异对比和自动合并
- 内置新闻/电商/公告三个配置模板
- 智能提取：粘贴 HTML 自动推荐 XPath
- 选择器在线测试功能
- 任务监控页：实时日志、进度条、资源监控
- 结果查看页：流式 CSV 浏览、完整分页、Excel 导出
- 任务历史管理（自动清理过期记录）
- 自动保存与草稿恢复
- 无 GUI 模式（`--headless` / `--run`）
- 首次启动快速体验引导
- 黑暗模式支持
- 系统托盘最小化
- 任务完成声音提示
- "请勿打扰"模式
- 日志导出隐私脱敏
- 错误上报隐私保护
- 配置导入/导出（团队共享）
- 选择器语法帮助页面（CSS/XPath/JSONPath）
- 完整用户文档（README + FAQ + 帮助页）

### 改进优化

- 双向同步采用防抖机制，避免循环触发
- 日志控制台自动裁剪，防止内存溢出
- 结果表流式加载，10 万行 CSV 不卡顿
- 可选依赖 `psutil` 优雅降级
- 所有 GUI 字符串通过 `_()` 国际化函数包裹
- 全部文件 I/O 使用 `pathlib.Path` + 显式 UTF-8 编码

### 缺陷修复

- （首个版本，无历史缺陷）

### 已知问题

- 智能提取仅支持叶子节点文本匹配，结构化提取需手动配置
- JSONPath 选择器测试暂不支持在线验证
- 远程任务调度功能尚未实现（预留接口）
